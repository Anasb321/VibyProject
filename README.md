# User levels
In the territories where Deezer is already available, we manage 3 kinds of end-users.
- ## Unlogged users:
- Users who are not registered or logged in on the Deezer service.
- Cannot add a mix/album/artist as a favorite.
- Cannot create a playlist.
- 30s clips listening restrictions.

## Freemium users:
- Users with a free Deezer account.
- Can add a mix/album/artist as a favorite.
- Can create a playlist.
- 30s clips listening restrictions.

## Premium / HiFi / Family users:
- Users who suscribed a paid account (learn more).
- Can add a mix/album/artist as a favorite.
- Can create a playlist.
- Unlimited listening in HQ.
- Mobile access
